# Motion direction

Один основной подход для сложных сцен — **GSAP + ScrollTrigger** (динамический import, ≈ 1 чанк на главной; на `/menu` и `/locations` GSAP не грузится). Простой UI — CSS (`transform`/`opacity`, `@starting-style`, нативный `<dialog>`).

Easing — токены из ТЗ: `--ease-out` (вход/выход), `--ease-in-out` (морфинг), `--ease` (hover/цвет). Микро 140 мс, UI 220 мс, крупные 420 мс; маркетинговые сцены — scrub (привязаны к скроллу, не «вязкие»).

## Правила

- Только `transform`/`opacity`/`clip-path` (+ один `backgroundPosition` у doodles). Layout не анимируется.
- Ни одного rAF-цикла: всё на ScrollTrigger; видео ставится на паузу вне зоны видимости.
- `gsap.matchMedia()`: desktop / mobile / reduced — разные сборки сцен, откат при unmount.
- `prefers-reduced-motion: reduce`: ни одного pin/scrub (проверено автотестом: `.pin-spacer` = 0), анимации входа CSS отключены, контент и состояния сохранены; страница 16.5k px вместо 28k.
- `MotionBoot` обновляет ScrollTrigger после шрифтов/загрузки.
