## Что нашёл и исправил в проходах polish

1. Орбитальные стаканы в категории «Молочные чаи» исчезали (`img max-width:100%` внутри 0-размерного родителя) и ломались от CSS `rotate` + GSAP → счёт ротации перенесён в GSAP.
2. Mobile hero: заголовок уезжал под первый экран → стейдж сжат до 37 svh, пузырь вынесен из-под текста.
3. Меню на phone расширяло layout viewport до 1208 px (grid) → `min-width:0`.
4. Тизер на phone: карточки по 276 px в колонке 178 → `grid-template-columns: minmax(0,1fr)`.
5. Ozerki matcha: убрана «Фисташечка» (по изображению меню её на Озерках нет) — **найдено при повторной сверке с оригиналом**; для Озерок добавлены собственные описания фруктовых чаёв (без кокосового мармелада).
6. Края вырезок стаканов (фиолетовая кайма) → эрозия маски 2→4 px.
7. «Слой за слоем»: белый текст на бирюзовом переходе — контент появляется только когда чернильный wipe закончился (`autoAlpha`).
8. Видео сборки (2.9 МБ) грузится за ~1.5 экрана до сцены, не в `<head>`.
9. `GSAP target not found` (пустой NodeList у карточки «Классика») → guard.
10. Нативные `<dialog>` вместо самописного focus trap; `aria-label` соцкнопок содержат видимый текст (WCAG 2.5.3).

## Известные ограничения (честно)

- **Performance 80–90** в lab-режиме (4× CPU, slow 4G): LCP 3.7–5.2 с — симуляция; реальный LCP по Chrome trace ≈ 1.3 с. Основной резерв — разбить `gsap` на отдельный route-chunk (уже динамический) и вынести hero-арку в AVIF на сервере.
- Вырезки стаканов — из меню 110×170 px: на больших экранах (hero ≥ 300 px) видна мягкость. Если у владельца есть оригиналы фото напитков — заменить `public/media/menu/<id>.webp` (имена = id позиций).
- Нет фото точки «Арена» (в архиве нет) и нормального фото «Дельфин» (кадр из ролика): есть слот `image` в `content/locations.ts`.
- Логотип — растр (из постера), векторного оригинала нет.
- Safari/Firefox не тестировались (только Chromium); `clip-path` + `@starting-style` имеют graceful fallback.
- Реальные Яндекс/2ГИС ссылки взяты из Taplink; их работоспособность в прод-сети не проверялась (редиректы короткие).
