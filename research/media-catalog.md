# Media catalog

Принцип: **только реальные материалы бренда**. Генерации нет. Все оригиналы остались в корне проекта; на сайт идут веб-версии.

## 1. Меню-вырезки стаканов (главный продуктовый визуал)

Реальные фотографии напитков TapiTi из официальных меню (VK-статья). Скрипт `scripts/extract-cups.mjs`: ищет стакан в сетке меню, убирает градиентный фон (оценка фона по полю + эллипс/трапеция конуса стакана), апскейл ×2, WebP с альфой.

- 104 файла → `public/media/menu/<itemId>.webp` (1.2 МБ суммарно, 10–25 КБ каждый)
- + `content/data/cups.json`: размеры и доминантный hue (из него считается цвет «подложки» карточки)
- Источник по приоритету: Дельфин (максимальное разрешение) → Чижова → Максимир → Арена.
- Ограничение: разрешение кропа ~110×170 px в оригинале → на карточках используем ≤ 330 px по высоте; для hero — крупно только 3 стакана.

## 4. Логотип и favicon

- Логотип: постер «Лого» (фото 1, 1268×882) → вырезан заливкой от границ (`public/brand/logo.webp|png`, 921×745, прозрачный).
- Favicon / apple-icon: лисёнок из логотипа на бирюзовой плашке (`app/icon.png`, `app/apple-icon.png`).
- OG-image: логотип + 4 стакана (`app/opengraph-image.png`, 1200×630).
- Векторного оригинала логотипа в архиве нет — запросить у владельца (сейчас растр, края слегка мягкие).

## 5. Тех. заметки

- `next/image` для фото (AVIF/WebP, responsive). Вырезки стаканов — `unoptimized` (уже WebP, 10–25 КБ).
- Видео не грузятся все сразу: `preload=metadata` + IntersectionObserver / ScrollTrigger play/pause; assembly — `preload=auto`, но только на главной в зоне сцены.
- `object-position`: hero 50% 40%, стена — по каждому тайлу, лисёнок — по центру постера.
