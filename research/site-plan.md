# IA + content model

## Маршруты

| Route | Назначение |
|---|---|
| `/` | История бренда: hero → сборка стакана → ритуал → категории → тизер меню → «5» → выбор точки → живая стена → лисёнок |
| `/menu` | Главный продукт: точка → поиск → категории → карточки → product sheet с КБЖУ. Состояние в URL (`?loc=&cat=&q=&item=`) — ссылкой можно поделиться, `?item=` открывает карточку |
| `/locations` | Пять глав: фото/адрес/этаж/ориентир/часы + «открыто сейчас» (время Воронежа) / Меню точки / Яндекс Карты / 2ГИС |
| `/sitemap.xml`, `/robots.txt`, OG, favicon | SEO |

Нет `/order`, корзины, чекаута (доставка не подтверждена).

## Меню — логика (location-first)

- Точка выбирается слева (desktop) / горизонтальным рейлом (phone) и хранится в URL + `localStorage`.
- Грид показывает **только позиции выбранной точки**; позиции, которых там нет, вынесены в сворачиваемый блок «Нет на точке … — но есть на других» (приглушены, подпись «Есть: …», цена «от»).
- Карточка: реальный стакан на подложке своего hue, ценник M, категория, название, 2 строки описания (скрыты на phone), `M 500 мл · L 700 мл ₽`, бейдж ккал (M, холодный).
- Product sheet: крупный стакан; переключатели размер (M/L) и температура (если есть «Тепл.» в таблице КБЖУ); КБЖУ (ккал/Б/Ж/У) именно для выбранного размера и температуры + пояснение basis и ссылка на источник; «Где есть» (кнопки точек с ценой, недоступные — зачёркнуты); похожие.
- «Классика» — отдельная таблица по объёму (350/450/500 мл) с раскрывающимся КБЖУ.
- Если КБЖУ нет — честная плашка «в официальной таблице не опубликовано», пустых блоков нет.

## Данные (`content/`)

```
content/types.ts       Location / MenuItem / Kbzhu / OrderingConfig …
content/locations.ts   5 точек, hours data-driven, ссылки на карты, openStatus()
content/menu.ts        обёртка над data/menu.json + cups.json
content/data/*.json    генерируются scripts/build-data.mjs, extract-cups.mjs, build-media.mjs
content/ordering.ts    { mode: 'none' }
content/brand.ts       факты, цитаты (со ссылками на посты), копирайт категорий
content/social.ts      curated «живая стена», колода лисёнка
scripts/data/menu-source.mjs   транскрипция меню (единственная ручная часть; каждая строка — из изображения VK)
```

### Pipeline меню (из ТЗ §4)

1. Ручная транскрипция 7 изображений → `menu-source.mjs` (tier-цены по категориям и точкам + исключения).
2. Парсер `scripts/parse-kbzhu.mjs` — HTML-таблица VK → raw JSON (423 строки).
3. `build-data.mjs`: нормализация имён **только для сопоставления** (ё→е, регистр, пунктуация), + явный словарь опечаток источника; привязка точек, КБЖУ (по секции и имени), вычисление `offers` M/L по точке.
4. Валидация: уникальные id (бросает исключение при дубле), цена обязательна для каждой точки, у каждой позиции `source.menu`, 0 позиций без картинки, нераспознанные строки КБЖУ — в `unmatched-kbzhu.md`.

### Итоги

- Позиции: **104** уникальных + 7 «Классика» (одинаковая во всех точках).
- По точкам (без классики): Чижова 102 · Арена 94 · Дельфин 94 · Максимир 72 · Озерки 62.
- КБЖУ: 72 из 104 + 7 из 7 классики. 32 позиции — без строки в таблице (не вычислялось).

## Архитектура

- Next.js 16 (App Router), React 19, TypeScript strict, CSS (tokens + файлы по сценам; Tailwind не нужен — фирменная система вся на CSS-переменных; осознанное отклонение от «базового варианта» ТЗ), `next/font` (Unbounded, Onest), `next/image`, GSAP+ScrollTrigger только на `/`.
- Server components для данных/маршрутов; client только там, где интерактив/анимация.
- Все страницы статически пререндерятся.
